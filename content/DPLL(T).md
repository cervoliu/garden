求解 [[Satisfiability Modulo Theory|SMT]] 问题可满足性的算法，框架如下：

![[DPLL(T) algorithm framework.png]]

包含两个核心部分：
- 核心求解器（Core Solver）：运行 DPLL 算法，用于处理一阶逻辑公式的布尔结构。
- 理论求解器（Theory Solver）：对于每个理论 $\mathcal{T}$ ，相应的理论求解器（称为 $\mathcal{T}$-求解器）运行判定算法检查 $\mathcal{T}$ 的公理是否成立。

设输入一阶逻辑公式（或称 SMT 公式）为 𝛹 ，DPLL(T) 首先执行布尔抽象（Boolean Abstraction）：将 𝛹 中每个原子抽象为命题（或称布尔变量），得到命题逻辑公式 ℬ(𝛹 )。 ℬ(𝛹 ) 是 𝛹 的上近似：若 ℬ(𝛹 ) 不可满足，则 𝛹 同样不可满足；但 ℬ(𝛹 ) 可满足不一定代表 𝛹 可满足，因为 ℬ(𝛹 ) 的可满足模型可能违反一阶理论的公理。

根据布尔抽象引入的近似，DPLL(T) 框架的典型工作方式是基于抽象精化的迭代求解。

如图所示，该框架迭代执行下列两个步骤：
1. 抽象公式求解：核心求解器调用 DPLL 算法求解 ℬ(𝛹 ) 的可满足性。若 ℬ(𝛹 )不可满足，则 𝛹 同样不可满足，算法终止；否则，记 𝛼 为 ℬ(𝛹 ) 的可满足模型。
2. 理论精化：对于 𝛹 涉及到的每个理论 𝒯 ，DPLL(T) 调用对应的 𝒯-求解器检查 𝛼 是否满足 𝒯 的公理，若所有理论的公理均得到满足，则 𝛹 可满足，算法终止；反之，若 𝛼 与某理论的公理冲突，对应的理论求解器分析冲突子句解释冲突成因，并将该子句添加到 ℬ(𝛹 ) 中，返回步骤 1 重新求解。
