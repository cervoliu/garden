## cuBLAS

cuBLAS 是 NVIDIA 提供的一个用于 GPU 加速的**闭源**库，全称为 CUDA Basic Linear Algebra Subroutines，即 CUDA 基本线性代数子程序库。===cuBLAS 库实现了大量针对 NVIDIA GPU 高度优化的线性代数运算===，这些运算是科学和工程计算中常见的操作，比如矩阵乘法、向量点乘等。

cuBLAS 的主要特点包括：

1. **GPU 加速**：cuBLAS 利用 GPU 的并行处理能力，可以显著加速大规模线性代数运算。
2. **行业标准 BLAS API**：cuBLAS 提供了与基础线性代数子程序（BLAS）标准兼容的 API，使得开发者可以轻松地将现有的 CPU 上的线性代数代码移植到 GPU 上。
3. **批量运算支持**：cuBLAS 支持对多个矩阵操作进行批量处理，进一步提高性能。
4. **跨多个 GPU 的执行**：cuBLAS 支持在多个 GPU 上并行执行运算，适用于多 GPU 系统。
5. **混合精度支持**：cuBLAS 提供了对单精度和双精度浮点数的支持，以及对半精度浮点数的支持，允许开发者根据需要选择合适的数值精度。
6. **易于使用**：cuBLAS 的 API 设计简洁直观，易于学习和使用。

cuBLAS 库广泛应用于高性能计算（HPC）和人工智能（AI）应用中，如深度学习训练和科学模拟，它为这些计算密集型任务提供了重要的性能加速。

## cuBLASLt

===cuBLASLt 是 NVIDIA 提供的一个轻量级的矩阵运算库，专注于执行 GEMM 操作。===

cuBLASLt 提供了一种新的灵活 API，它增加了在矩阵数据布局、输入类型、计算类型以及通过参数可编程性选择算法实现和启发式方法方面的灵活性。

以下是关于 cuBLASLt 的一些关键特性：

1. **灵活性**：cuBLASLt 允许在矩阵数据布局、输入类型、计算类型等方面提供更多的灵活性。
2. **参数可编程性**：用户可以通过参数可编程性选择算法实现和启发式方法，从而为特定的 GEMM 操作定制性能。
3. **多阶段 GEMM API**：cuBLASLt 提供了一个多阶段 GEMM API，允许应用程序利用最新的 NVIDIA 架构特性以获得最佳性能。
4. **融合操作**：cuBLASLt 支持将两个或多个内核“组合”为单个内核，从而允许重用数据并减少数据移动。
5. **混合精度执行**：cuBLASLt 支持混合精度和低精度执行，这在深度学习和其他需要动态精度调整的计算中非常有用。
6. **适用于最新架构**：cuBLASLt 旨在利用 NVIDIA 最新的 GPU 架构特性，如在使用 NVIDIA Hopper GPU 时提供高性能。
7. **设备扩展**：cuBLASLt 作为设备扩展，允许在 CUDA 内核内部执行 BLAS 计算，这可以提供更高的性能，尤其是在处理大型矩阵运算时。
8. **适用于大规模问题**：对于无法完全放入 GPU 内存的大型问题，或者需要单节点多 GPU 支持的应用程序，cuBLASLt 是一个合适的选择。
9. **与 cuBLAS 的关系**：cuBLASLt 是 cuBLAS 库的一部分，提供了对 GEMM 操作的额外优化和灵活性。
10. **适用于高性能计算**：cuBLASLt 适用于需要高性能计算（HPC）的应用，如科学模拟、数据分析和机器学习。

cuBLASLt 的设计目标是提供一种高效的方式来执行矩阵乘法和其他线性代数操作，特别是在需要高度优化和定制化计算的场景中。开发者可以利用 cuBLASLt 来提升应用程序在 NVIDIA GPU 上的性能。

## cuBLASDx

cuBLASDx 是 cuBLAS 库的一部分，它提供了一组设备级可执行的扩展，允许开发者在 CUDA 内核中直接执行 GEMM 操作。cuBLASDx 旨在提高性能，特别是在处理大型矩阵运算时，通过减少数据传输和延迟来优化性能。

以下是 cuBLASDx 的一些关键特性：

1. **设备级操作**：cuBLASDx 允许在 CUDA 内核中执行 GEMM 操作，这意味着可以在 GPU 上更接近数据的地方执行计算，从而减少数据传输和潜在的延迟。
2. **融合内核**：cuBLASDx 支持将多个操作融合到单个内核中，这样可以减少内存访问次数和内核启动开销，提高整体性能。
3. **高级接口**：cuBLASDx 提供了高级接口，允许开发者更灵活地控制 GEMM 操作的执行，包括矩阵布局、数据类型和计算类型等。
4. **参数可编程性**：cuBLASDx 允许通过参数可编程性选择算法实现和启发式方法，从而为特定的 GEMM 操作定制性能。
5. **多 GPU 支持**：虽然 cuBLASDx 主要针对单个 GPU 上的性能优化，但它也可以在多 GPU 系统中使用，以实现更大规模的并行计算。
6. **适用于复杂应用**：cuBLASDx 适用于需要高性能计算（HPC）的应用，如科学模拟、数据分析和机器学习。
7. **与 cuBLAS 的兼容性**：cuBLASDx 作为 cuBLAS 的一部分，与 cuBLAS 的其他组件兼容，允许开发者利用现有的 cuBLAS 知识。
8. **性能优化**：cuBLASDx 旨在利用 NVIDIA GPU 的最新架构特性，如在使用 NVIDIA Ampere GPU 时提供高性能。

cuBLASDx 的设计目标是提供一种高效的方式来执行矩阵乘法和其他线性代数操作，特别是在需要高度优化和定制化计算的场景中。开发者可以利用 cuBLASDx 来提升应用程序在 NVIDIA GPU 上的性能，尤其是在执行大规模矩阵运算时。

## cuBLASXt

cuBLASXt 是 cuBLAS 库的一个扩展，它提供了一组高级 API，旨在提高在多 GPU 系统上进行高性能计算时的易用性和灵活性。cuBLASXt 的设计考虑了跨多个 GPU 进行数据操作和计算的需求，它支持混合 CPU-GPU 计算，并允许在不同的设备上分布数据和计算任务。

以下是 cuBLASXt 的一些关键特性：

1. **多 GPU 支持**：cuBLASXt 设计用于在单个节点上跨越多个 GPU，提供了在这些 GPU 上执行 BLAS 级别 3 操作的能力。
2. **混合 CPU-GPU 计算**：cuBLASXt 支持将数据保留在 CPU 上，同时在 GPU 上执行计算，这对于某些需要 CPU 和 GPU 紧密协作的应用场景非常有用。
3. **动态数据管理**：cuBLASXt 能够处理在不同设备（CPU 或 GPU）上的数据，并负责将数据和操作调度到一个或多个 GPU 上。
4. **高级操作**：cuBLASXt 提供了对一些高级线性代数操作的支持，例如执行厄米秩更新的 `herk` 操作。
5. **性能优化**：cuBLASXt 旨在优化大型矩阵运算的性能，尤其是在分布式内存系统中。
6. **简化开发**：cuBLASXt 提供了简化的 API，使得开发者可以更容易地利用多个 GPU 的计算资源，而无需深入了解底层的复杂性。
7. **与 cuBLAS 的兼容性**：cuBLASXt 与 cuBLAS 兼容，允许开发者利用现有的 cuBLAS 知识来扩展到多 GPU 计算。
8. **适用于复杂应用**：cuBLASXt 适用于需要处理大规模问题的应用程序，如科学计算、数据分析和机器学习。

cuBLASXt 的设计使得它成为在多 GPU 环境中进行高性能计算的有力工具，特别是对于那些需要处理大型数据集和复杂计算任务的应用。通过使用 cuBLASXt，开发者可以更高效地利用 NVIDIA GPU 的并行处理能力，从而加速计算密集型应用的执行。
