On algebraic rewrite verification:
- TASO: Develop a set of axioms which serves as rewrite rules(represented as s-exprs) for potential optimization. The axioms themselves are only verified on small-shape instances. 
- TENSAT: Same set of rewrite rules as TASO in experiment. Try to apply rewrites via equality saturation.
- Both TASO and TENSAT are essentially superoptimizer, so they focus more on optimization than verification. 
- TensorRight: offer (semi-)automatic verification of rewrite rules for arguments of arbitrary rank and size.
